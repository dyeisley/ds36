
The test harness only ever grows the database by adding to the CUSTOMERS, ORDERS, ORDERLINES, 
REVIEWS, MEMBERSHIP, and REVIEW_HELPFULNESS tables. The idea here is to implement a 
manager thread (1 per store) to do additional types of database transactions, bulk updates, 
deletes, delete cascade, etc. 

The goal was to add additional operations that would happen in a store without harming user OPM too much.
